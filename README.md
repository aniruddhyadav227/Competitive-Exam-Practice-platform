# ExamArena — Competitive Exam Practice Platform 🚀

ExamArena is a lightweight, frontend-only web application designed to help students and tech enthusiasts practice multiple-choice questions for competitive exams. It features a clean, responsive UI with interactive quizzes focusing on Data Structures, Algorithms, and Core Computer Science concepts.

## 🌟 Features
- **Zero Backend Required:** The entire application runs directly in the browser using JavaScript arrays.
- **Interactive UI:** Smooth transitions between Welcome, Quiz, and Result screens.
- **Real-time Feedback:** Instantly highlights correct (green) and incorrect (red) answers.
- **Score Tracking:** Calculates and displays your final score at the end of the quiz.
- **Fully Responsive:** Works perfectly on both desktop and mobile screens.

## 🛠️ Tech Stack
- **HTML5:** For structuring the application.
- **CSS3:** For styling, modern UI design, and responsive layouts.
- **Vanilla JavaScript:** For DOM manipulation, quiz logic, and state management.

## 🚀 How to Run the Project
1. Clone or download this repository to your local machine.
2. Open the project folder in **Visual Studio Code**.
3. You can run this project in two ways:
   - **Method 1:** Simply double-click the `index.html` file to open it in your default web browser.
   - **Method 2:** Install the "Live Server" extension in VS Code, right-click on `index.html`, and select *Open with Live Server*.

## 💡 Why This Project?
This project is built to practice frontend logic while creating a useful tool for revising core concepts like BSTs, Queues, and SQL queries—perfect for brushing up before tackling problems on platforms like LeetCode or HackerRank.
